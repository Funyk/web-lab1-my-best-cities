## Дані та точні правила

```js
const noiseLevels = [
  42, 55, 61, 78, 83, 67, 49, 72, 91, 58, 64, 76,
  53, 47, 88, 69, 74, 82, 95, 51, 71, -1, 85, 63,
  79, 39, 141, 86
];
```

Підтверджені пороги: `warningLevel = 70`, `criticalLevel = 85`; допустимі межі — `30` і `130`. Це **навчальні умови задачі, а не нормативи шуму**.

| Перевірка | Точна умова |
| --- | --- |
| Коректність | `Number.isFinite(level) && level >= min && level <= max` |
| Без перевищення | Коректний `level <= warning` |
| Попередження | Коректний `warning < level && level <= critical` |
| Критичний | Коректний `level > critical` |

`Number.isFinite` не перетворює рядок `"70"` на число. `NaN`, `Infinity`, `-Infinity`, `null`, `undefined` і логічні значення відхиляються. Пороги перевищуються строго: **70 — без перевищення, 85 — попередження, 86 — критичний**.

«Понад warning» включає попередження **разом із критичними**. Три окремі класи не перетинаються; їхня сума дорівнює кількості коректних даних. Позиція для людини завжди дорівнює індексу масиву плюс один.

## Функції та цикли

| Функція | Форма та призначення |
| --- | --- |
| `isValidLevel(level, min, max)` | Declaration; спільна перевірка коректності, повертає boolean |
| `calculateAverage(sum, validCount)` | Declaration; повертає `sum / validCount` або `null` |
| `summarizeLevels(data, warning, critical, min, max)` | Expression у `const`; `for...of` з `continue`, сума, min/max і категорії |
| `findFirstCritical(data, critical, min, max)` | Declaration; індексний `for` з `break`, результат `{ value, position }` або `null` |
| `findRecovery(data, firstCriticalPosition, warning, min, max)` | Declaration; `while`, пошук третього безпечного поспіль після першого критичного |
| `findFirstValid(data, min, max)` | Declaration; перевірка порожнього масиву, потім `do...while` |
| `describeInvalidLevels(data, min, max)` | Declaration; індексний цикл для тексту відхилених позицій |
| `analyzeMeasurements(..., summaryOperation)` | Declaration; синхронно викликає переданий алгоритм і збирає результати |
| `createConclusion(result)` | Declaration; повертає текстовий висновок |
| `formatLevel(value)` | Arrow з одним параметром; форматує підпис рівня |
| `isAbove(value, threshold)` | Arrow з двома параметрами; перевіряє строге перевищення |
| `printReport(result, warning, critical, min, max)` | Єдина функція представлення; друкує згрупований звіт |

`for...of` потрібний для повного перегляду значень. Некоректні збільшують лічильник відхилених, після чого `continue` не допускає їх у статистику. Мінімум і максимум спочатку дорівнюють `null`; перше коректне значення ініціалізує обидва, подальші порівнюються з ними. Середнє зберігається неокругленим; `.toFixed(2)` застосовується тільки під час показу.

`for` у пошуку першого критичного зберігає індекс. `break` зупиняє пошук на першому коректному перевищенні, не на останньому. Значення 141 не стає критичним, бо спершу відхиляється перевіркою коректності.

`while` починається **після** першого критичного. Коректне значення не вище 70 збільшує серію; некоректне або понад 70 скидає її до нуля. Індекс збільшується на кожній ітерації. Повертається позиція третьої безпечної точки; якщо критичної точки або завершеної серії немає — `null`.

Для непорожнього масиву `do...while` доречний, бо перший кандидат потрібно перевірити хоча б один раз. Окрема перевірка `data.length === 0` перед циклом запобігає зверненню до неіснуючого першого елемента. Якщо весь набір некоректний, результат також `null`.

Методи `filter`, `reduce`, `Math.min`, `Math.max` або інші готові обходи не підміняють алгоритми у `js/monitoring.js`. Вхід залишається масивом чисел; прості об’єкти використовуються лише для повернення пов’язаних результатів. Класи, прототипи, об’єктна модель датчиків, DOM, події та асинхронність не застосовуються.

### Синхронний callback

У фінальному виклику `summarizeLevels` передається як **значення функції без дужок**:

```js
const monitoringResult = analyzeMeasurements(
  noiseLevels, warningLevel, criticalLevel,
  minValidLevel, maxValidLevel, summarizeLevels
);
```

Усередині `analyzeMeasurements` параметр `summaryOperation` викликається з потрібними аргументами, а його `return` записується у `statistics`. Це синхронний callback: обчислення завершується до повернення `analyzeMeasurements`. Передавання `summarizeLevels(...)` означало б передати вже обчислений об’єкт, а не алгоритм.

## Експерименти для Browser Console

Наведені шість фрагментів залишені для **окремого введення в Console під час захисту**, а не для додавання до `monitoring.js`. Очікування були визначені до перевірки. Під час фактичного QA ці самі операції виконано у браузері через шість окремих зовнішніх JavaScript-файлів тимчасової HTTP-сторінки; введення тексту через інтерфейс DevTools не використовувалося. Для збереження результатів вирази обгорнуто в `console.log`, а складені результати серіалізовано через `JSON.stringify`. Отримано реальні журнали браузера, зокрема два навмисні неперехоплені `ReferenceError`. Тимчасові експериментальні файли не підключені до кінцевого сайту. Перед повторною перевіркою остаточного звіту очистіть Console та перезавантажте сторінку без збереження старих повідомлень.

### 1. log, warn та error

```js
console.log("Навчальна перевірка запуску JavaScript");
console.warn("Навчальна демонстрація попередження про тестові дані");
console.error("Демонстраційне повідомлення Console; це не збій програми");
```

Очікування: звичайне повідомлення, попередження й повідомлення error з різним оформленням і посиланнями на джерело. У фінальному файлі цих демонстраційних повідомлень немає. Реальний фінальний `console.warn` повідомляє про 13 перевищень, а не про збій виконання.

### 2. Порогові вирази, типи та return

```js
[70 > 70, 85 > 85, 86 > 85]
// Очікування: [false, false, true]

[isValidLevel(30, 30, 130), isValidLevel(130, 30, 130), isValidLevel(131, 30, 130)]
// Очікування: [true, true, false]

[Number.isFinite("70"), Number.isFinite(NaN), Number.isFinite(Infinity)]
// Очікування: [false, false, false]

calculateAverage(1778, 26)
// Очікування: 68.38461538461539
```

### 3. Function Declaration до тексту оголошення

```js
{
  console.log(lab4EarlyDeclaration([70, 85, 86], 85, 30, 130));
  function lab4EarlyDeclaration(data, critical, min, max) {
    return findFirstCritical(data, critical, min, max);
  }
}
```

Прогноз: `{ value: 86, position: 3 }`. Оголошення функції доступне в своїй області до його текстової позиції завдяки hoisting.

### 4. Function Expression у const до ініціалізації

```js
{
  console.log(lab4EarlyExpression([70, 85, 86], 70, 85, 30, 130));
  const lab4EarlyExpression = function (data, warning, critical, min, max) {
    return summarizeLevels(data, warning, critical, min, max);
  };
}
```

Прогноз: **ReferenceError** — звернення до `const` до її ініціалізації (temporal dead zone). Це навмисний окремий експеримент, не помилка фінальної програми. Такий виклик не зберігати у робочому JS.

### 5. Блочна область видимості

```js
{
  const lab4BlockLevel = 70;
  console.log(lab4BlockLevel);
}
console.log(lab4BlockLevel);
```

Прогноз: спочатку 70, потім ReferenceError. Змінна `const` створена лише всередині блока.

### 6. Тестові масиви як аргументи

```js
analyzeMeasurements([], 70, 85, 30, 130, summarizeLevels)
analyzeMeasurements([-1, 141], 70, 85, 30, 130, summarizeLevels)
analyzeMeasurements([70, 85, 86], 70, 85, 30, 130, summarizeLevels)
analyzeMeasurements([91, 50, 60, 72, 55, 60, 70], 70, 85, 30, 130, summarizeLevels)
analyzeMeasurements([91, 50, 60, -1, 55, 60, 70], 70, 85, 30, 130, summarizeLevels)
```

Ці функції повертають результати й не друкують нових звітів самі. Основний `noiseLevels` не переприсвоюється та не змінюється.

## Пояснення для захисту

- **Параметр і аргумент:** `threshold` в описі `isAbove(value, threshold)` — параметр, а передане 85 — аргумент. Дані й пороги обчислювальні функції отримують через параметри.
- **return і console.log:** `return` передає результат виклику наступному обчисленню; `console.log` лише показує значення. Функції аналізу нічого не друкують, а `printReport` тільки представляє готові результати.
- **Scope:** глобальні константи задають основний набір; локальні лічильники існують у своїх функціях; `let index` циклу `for` і `const level` у його блоці недоступні зовні відповідної області.
- **Hoisting:** Function Declaration доступна до тексту оголошення. У Function Expression функція стає значенням `const` лише при виконанні ініціалізації; до цього звернення заборонене.
- **Arrow Function:** короткі `formatLevel` та `isAbove` мають зрозуміле неявне повернення. Це дві реально застосовані операції з одним і двома параметрами.
- **break і continue:** `continue` відкидає поточний некоректний запис; `break` завершує пошук після першого критичного. Для recovery некоректний запис не просто пропускається, а обнуляє безпечну серію.
- **null:** означає відсутній результат, а не нульовий шум. Для порожнього чи повністю некоректного набору середнє, мінімум і максимум дорівнюють `null`.

Після експериментів відкрито кінцеву сторінку заново. Неперехоплених помилок у чистому запуску немає. Одне змістовне `console.warn` повідомляє про 13 перевищень 70 dB; це діагностика навчальних даних, а не помилка виконання.
